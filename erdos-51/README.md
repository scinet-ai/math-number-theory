# Erdős #51 — unconditional limsup n_a/a ≥ 2 via the Fermat-number dichotomy, obstruction lemmas, and a certified record table to 3.06×10¹⁰

**Problem** (Erdős; erdosproblems.com/51). For a totient value a, let n_a
(= f(a) below) be the least n with φ(n) = a. Does n_a/a → ∞ along an infinite
set of totient values? OPEN; the page notes it "cannot be resolved with a
finite computation", and Terence Tao's forum heuristic predicts the answer is
likely **negative** (bounded ratio).

**Outcome framing: partial.** The problem wants ratio → ∞; the family proved
here has constant ratio 2. The rigorous positive takeaway is the first proved
constant, **limsup n_a/a ≥ 2**, plus quantitative obstructions explaining why
pushing past 2 is hard — consistent with (and mildly supporting) Tao's
negative prediction.

## What this work establishes

1. **Theorem 1 — the Fermat-number dichotomy** (`proof_ratio2_family.md`;
   unconditional): for k ≥ 1, if some bit i of k's binary expansion has the
   Fermat number F_i = 2^(2^i)+1 **composite**, then the least preimage of
   a = 2^k is exactly 2^(k+1) (ratio exactly 2); if every bit indexes a
   Fermat **prime**, then n_{2^k} = ∏_{i∈bits(k)} F_i ∈ (2^k, 2^(k+1))
   (ratio < 2). Since F_5 = 641·6700417 is composite (Euler), infinitely
   many totient values have n_a/a **exactly 2**, hence
   **limsup n_a/a ≥ 2 — the first proved constant recorded for #51**.
   Unconditionally n_{2^k} = 2^(k+1) for **every** 32 ≤ k < 2³³ (F₅…F₃₂ all
   composite).
2. **Obstruction lemma pack** (`proof_obstruction_lemmas.md`): if a totient
   value has n_a/a ≥ K then every preimage n satisfies
   ∏_{p|n} p/(p−1) ≥ K; elementarily ω_odd(n) ≥ (K²−4)/8, equivalently the
   boxed bound **f(a)/a ≤ 2√(2v₂(a)+1)** for every totient value a (so any
   YES-family must have v₂(a) → ∞); with explicit Mertens bounds,
   ω_odd(n) ≥ e^(0.5526K)/(0.5526K) − 1 for K > 10.226 (exponential v₂
   forcing); combining recovers the known bound
   f(a)/a ≤ (e^γ + o(1))·loglog a with constant 1.8094 vs e^γ ≈ 1.7811.
3. **Certified census** (`computation.md`): a segmented totient sieve over
   n ≤ 1.94×10¹¹ plus a fully elementary completeness lemma (Lemma C:
   ω ≤ 10 ⇒ n/φ(n) ≤ R(10); ω ≥ 11 ⇒ φ(n) ≥ φ(31#)) proves the **exact**
   table of f(a) for **all 3,903,102,222 totient values
   a ≤ A_max = 30,641,761,281**: complete census of the 31,043 values with
   f(a)/a ≥ 2; global record **f(a)/a = 2.043447 at
   a = 387383296 = 2¹⁶·23·257** (f(a) = 791597265 = 3·5·17·47·257²); no
   value reaches 2.05. The running-record positions
   2, 8, 128, 5888, 2037248, 387383296 reproduce **OEIS A393265** exactly,
   **certifying that sequence's completeness within our range** (its own
   scan, to 1.2×10¹¹, is uncertified).

## Trusted base / caveats

- Theorem 1 and the census certification (Lemma C) are elementary and
  self-contained. The "ratio = 2 for all 32 ≤ k < 2³³" refinement cites the
  compositeness status of F₅…F₃₂ from the Fermat-factoring status page
  **prothsearch.com/fermat.html** (smallest Fermat number of unknown
  character: F₃₃) — a disclosed data citation; the infinitude/limsup ≥ 2
  headline needs only Euler's F₅ factorization.
- **Rosser–Schoenfeld citation caveat** (disclosed verbatim in
  `proof_obstruction_lemmas.md`): the exact numbered form of the [RS62]
  Mertens product inequality (validity threshold x ≥ 285) was checked
  against secondary sources (Integers 20 (2020) #A103; C. Axler,
  arXiv:1703.08032) but not re-derived; only the explicit constants
  (0.5526, 10.226) in Theorem 5(ii) lean on it — Theorem 4 and 5(i) are
  independent and fully elementary.
- AMM Problem E3361 (JSTOR 2323869) is paywalled and was **not read**; the
  classical prior art for the 2^k/Fermat dichotomy is attributed via the
  T. D. Noe comment on OEIS A002181 and Guy's UPNT B36/B39 (Guy not re-read
  directly). Theorem 1's classification is claimed only as a complete
  write-up of classical territory; the unconditional exact-ratio-2
  infinitude + limsup ≥ 2 *as a statement about #51* is what appears
  unrecorded (search log: `novelty.md`).
- No paywalled PDFs or scraped pages are redistributed here; all sources
  cited by DOI/URL.
