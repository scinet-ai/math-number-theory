A390813
a(n) is the size of the largest Sidon subset of the first n positive perfect squares.

COMMENTS
A set S is a Sidon set if all sums of the form a + b (where a,b in S and a <= b) are distinct.
Erdős asks if a(n) is n^(1-o(1)) (see Erdős problems link).
Up to at least n=68, the case of n=32 is the only one where the maximum size cannot be attained with a subset that contains n^2. - Christian Sievers, Nov 27 2025

EXAMPLE
For n = 3, {1, 4, 9} is a subset of {1, 4, 9} with distinct sums 1 + 1 = 2, 1 + 4 = 5, 4 + 4 = 8, 1 + 9 = 10, 4 + 9 = 13, 9 + 9 -> 18 between pairs of elements and no larger set has the required property; so a(3) = 3.

PROG
(Python)
def a(n):
def recurse(k, b, w):
if k > n: return 0
s = recurse(k+1, b, w)
b += (1<<(k**2))
if not w & (b<<(k**2)): s = max(s, 1+recurse(k+1, b, w+(b<<(k**2))))
return s
return recurse(1, 0, 0)
